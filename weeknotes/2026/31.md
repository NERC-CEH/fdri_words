## Timeseries processing pipeline

## Public UI

- Tooltips styling have now been made consistent across the UI
- Added FAQ page
- Added Gridded Data Service learning page
- User can now specify network and site in the URL for the timeseries explorer as another way to select network/sites. 

## Ingestion

The EA and SEPA workflows have recently been separated into their own networks with their own metadata in the metadata store. This means some changes were required across our ingestion services, the API, the infrastructure and the UI to get them viewable within the UI. Additionally, a new 15 minute rainfall ingester has been deployed. To come will be a 15minute level EA ingester, a daily rainfall EA ingester and a 15minute flow SEPA ingester.

## Spatial API and UI

We now have spatial data in the production UI, for example https://dri-ui.dri.ceh.ac.uk/fdri/spatial?layers=3,26,23,21,2

In addition, a number of extra features have also been added, including the ability to show / hide the list of selected layers, modify the icon size for point based layers, expand the map to fill the screen and show/hide the legend panel.
