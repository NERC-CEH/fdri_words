# 2026 Week 33 (week beginning 10-08-2026)

You can tell that the September soft launch is looming by the number of prioritization meetings we are having.  However, it has kept us razor focused on making sure everything is ready and maybe not contributed quite so much to this weeknotes.  However, here is hopefully a representative selection of features and fixes we've achieved.

## Metadata
The metadata has been flooded with FDRI sites and dataset metadata, now appearing nicely on the UI.
New QC'd datasets, and aggregeated datasets are coming very soon

## Timeseries processing pipeline

**Milestone**: All COSMOS methods are now in the timeseries processor! 

## Public UI

- The spatial learn about page has been updated to use an up-to-date image of the spatial UI
- Bug fix to ensure variables are cleared when a new site is selected, preventing the wrong variables appearing for a given site in the timeseries data explorer.
- New EA datasets available in the UI.
- EA Flow and Level datasets can now be distinguished - the UI now uses the unique `id` from the metadata to uniquely identify variables.
- The developers working on the Catalogue have added a nice Learn About page (shown below), together with two step-by-step data stories all helping guide new user's through it.
