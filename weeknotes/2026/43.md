# 2026 Week 43 (19/10/2026) - DRAFT

No week notes have been put out since the launch. This set of week notes covers updates since launch. 

## Metadata
- Added implicit min/max values to relevant variables in metadata, for example Albedo should be between 0 and 1, variables measured as a percentage should be between 0 and 100.
  Updates to templates and ontology were required for these changes to be visible in the metadata API.

## Public UI
- data-API and UI now read the new min/max values from the metadata to cap the plot bounds at sensible values.
- Core, QC, infill and correction flags are now displayed in an optional mosaic chart displayed below the timeseries data explorer.
- A user can now specify manual min/max axis bounds. 
- Several minor bug fixes/updates were made:
  - Drop down menus can now be collapsed more easily.
  - Added space around scroll bar tooltips to prevent text being cut off/over flow/overlap.
  - Removed incorrectly rounded min/max values on axis bounds.
