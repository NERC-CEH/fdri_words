## Public UI
Several updates have been made to the UI this month

### Timeseries Data Explorer
- Plots persist if a user navigates away from and back to the timeseries data explorer so their progress isn't lost.
- Discreet datasets such as the RCA Depth are now scatter by default.
- Bar charts now use timeAnchors from the metadata to determine if the bar should represent the preceding/proceeding resolution period
- Improved readability of time resolutions - a longer term solution driven by TimeStream to come later.
- Networks, sites and variables now displayed in alphabetical order, with 'is loading messages'
- No data availble warning message added
- More space for legend when long list of variables added to a plot.
- Zoom state now persists while making changes to a plot so a user doesn't lose their place.
- Improved date picker: can only pick start/end times from their respective calendars and error messages so can't pick start/end date after/before end/start date!
- Several improvements to efficiency of plots, including caching when making variables/plots hidden/visible to prevent long reload times
  and down-sampling to reduce loading times for dense data over long time periods.

### Spatial Explorer
Now has a data story!

The spatial explorer has been transformed over the last month. Data has been loaded for all three FDRI catchments; the Chess, Upper Tweed and Upper Severn. Additional supporting layers have also been added at a UK wide scale such as the land cover map, 50m elevation and river networks.

Any layers depicting elevation data (e.g. those in the DEM / DSM / DTM categories) have been recoloured with underlying hillshading applied to further enhance visibility of how the terrain changes. A standardised colour palette has been used 

Usability has been improved in a number of ways:
- A number of performance issues have been addressed, mostly concentrating on improving the efficiency of data fetching when loading or changing the visibility of layers. 
- Loading indicators have been added to show when the UI is "thinking"
- The selected layer panel has been redesigned to group all layers together, regardless of their source location. This has allowed drag and drop reordering of layers to be implemented. 
- The order of layers now represents the order of visibility, with the layers at the top of the list most visible and those at the bottom will be at the bottom of the stack.
- Select and clear all buttons have been added, on a per-location basis and to clear the UI of all layers currently loaded.
- Usability on mobile devices has been improved, with the focus on maximising the map view on smaller screens
- Location boundary visualisation toggles have been redesigned to be easier to identify and use.
- Options to change the line width and colour of linestring / polygon type layers have been added
- The initial icon used to represent a set of points has been standardised across data categories. For example all rainfall layers will have a triangle icon, all river flow a square etc. 

3D mode has been removed. With the hillshading applied to the terrain type layers, the 3D rendering was increasingly inaccurate. As such it was decided to temporarily remove the 3D functionality until we can produce true 3D terrain layers instead of relying on the underlying colourmap
